# Day 2 - Azure Virtual Machine (VM)

## Objective
Understand how to create and manage a Virtual Machine in Azure.

---

## What I Did

- Created Virtual Machine (VM-AZ104-01)
- Selected B-series size (cost optimized)
- Configured username and password
- Connected using RDP (Remote Desktop)
- Logged in successfully
- Opened Command Prompt (Admin)
- Ran basic commands:
  - hostname
  - ipconfig
  - systeminfo

---

## Issues Faced & Fixes

### 1. Marketplace Error
- Issue: Unable to deploy VM due to subscription restriction
- Fix: Selected supported image

### 2. Login Failed
- Issue: Credentials not working
- Fix: Used correct format → VM-NAME\username

### 3. Black Screen / No GUI
- Issue: Only CMD visible
- Learning: VM was using Server Core (no GUI)

---

## Key Learnings

- VM is a cloud-based server
- Public IP is used for external access
- Private IP is used internally
- RDP is used for remote login
- Difference between Server Core and GUI
- Stop (Deallocate) is required to avoid cost

---

## Real-World Use Case

- Hosting applications on cloud servers
- Remote administration
- Scalable infrastructure
